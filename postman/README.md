# Home Care

Sistema para gerenciamento de cuidadores de idosos, desenvolvido com Python e Flask.

## Objetivo

O projeto tem como objetivo facilitar a comunicação entre administradores, cuidadores e familiares, centralizando as informações dos pacientes em uma única plataforma.

## Funcionalidades

    ### Administrador (ADMIN)

    * Criar usuários.
    * Editar usuários.
    * Excluir usuários.
    * Gerenciar permissões de acesso.
    * Cadastrar pacientes.
    * Gerenciar cuidadores.
    * Acompanhar relatórios diários.

    ### Cuidador

    * Visualizar pacientes.
    * Consultar medicamentos.
    * Registrar observações diárias.
    * Criar relatórios de atendimento.
    * Registrar entrada e saída (controle de ponto).

    ### Familiar

    * Acompanhar informações do paciente.
    * Visualizar medicamentos.
    * Consultar relatórios diários.
    * Acompanhar a evolução do paciente.
